# 📊 Enron Interactive Figures

## Charts

Full interactive charts with zoom, pan, hover tooltips, and export. Generated by `scripts/gen_interactive_charts.py`.

## Viewing

Open any HTML file in a browser:
```bash
open reports/eda/figures_interactive/*.html
```

## Generation

```bash
cd packages/Enron-Evaluation-Environment
python scripts/gen_interactive_charts.py
```

## Related Files

- `figures/` — Static PNG versions
- `scripts/gen_interactive_charts.py` — Chart generator
- `scripts/eda/` — EDA pipeline scripts
